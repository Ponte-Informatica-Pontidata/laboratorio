Esta issue fica **fixada** e recebe **um comentário por dia de trabalho**: é a nossa daily assíncrona.

## Como postar

Copie o modelo num comentário novo:

```markdown
**Fiz:** ...
**Vou fazer:** ...
**Bloqueios:** nenhum
```

## Combinados

- Curto: 3 linhas bastam. Links para issues e PRs ajudam (ex.: `Ponte-Informatica-Pontidata/radar-licitacoes#3`).
- **Bloqueio** = algo que te impede de avançar há mais de 1 hora. Diga o que já tentou.
- Não cole dados pessoais, senhas ou tokens.
- O tech lead lê todos os dias úteis e responde quando houver bloqueio.
