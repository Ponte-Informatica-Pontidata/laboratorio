# Avaliações

Um arquivo por sprint (`sprint-NN.md`) com as notas da [rubrica](../RUBRICA.md), as evidências (links) e
o combinado para a próxima sprint. O conteúdo é gerado pela ferramenta `montar_avaliacao` do MCP
(comando `/avaliar` no Claude Code) e revisado pelo tech lead antes do commit.

A estagiária lê, comenta na seção "Comentário da estagiária" e o arquivo é atualizado por PR.
